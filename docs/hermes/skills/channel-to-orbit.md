# Channel to Orbit

When the operator discusses work on Telegram or another Hermes channel, write it into Orbit so Pulse shows it.

## Steps

1. Identify project/concern from the message.
2. Create or update task via Orbit tools with `body` + `nextAction`.
3. Link email/files if referenced and available in Orbit.
4. Confirm briefly what landed in Orbit.

## Never

- Leave work-only in the chat transcript.
- Create Accept-chore suggestions instead of writing the concern.
